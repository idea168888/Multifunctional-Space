# **多元智能空間**

免費、無後端、無付費 API 的響應式創作網站。

公開網址：https://idea168888.github.io/Multifunctional-Space/

## 創作功能

- **LINE 靜態貼圖**：自有角色圖片或原創幾何角色搭配文字；8／16／24／32／40 張整組預覽；ZIP 包含貼圖、主圖、聊天室標籤。輸出 PNG RGB+alpha、72 dpi、透明留白。現有 PNG 可檢查簽章、尺寸、張數、RGB、DPI、透明度、空白圖片與留白。送審文字另存 TXT，提供全形字數與表情符號檢查。
- **影片**：可編輯分鏡模板、照片新增／排序／移除、直式／方形／橫式、完整顯示／裁切、每張字幕與選填配樂、進度、取消、下載與播放。依瀏覽器能力輸出 MP4 或 WebM，最多 12 張照片／60 秒。
- **圖文**：即時預覽、多尺寸、三種配色、對齊方式、選填背景圖片、文字自動縮放、PNG 下載及設計配置收藏／重開。
- **研發**：背景、假設、測量標準、實驗方法與觀察結果的可編輯企劃。
- **作品**：名稱／內容編輯、搜尋、主題篩選、收藏、排序、文字複製、TXT 下載、刪除。
- **自訂主題**：新增、改名、刪除；刪除主題保留作品並移到成品館。
- **資料**：文字草稿自動保存、舊版資料遷移、JSON 備份／匯入預覽／合併／取代、5 MB 上限提示。儲存失敗不顯示成功，也不產生假的已存作品。
- **分享**：本機產生網址 QR 碼、SVG 下載、網址複製、Unicode 網址及安全協定檢查。

## 免費與隱私邊界

純 HTML / CSS / JavaScript，正式網站沒有需要安裝的套件，也不呼叫付費 AI 或外部素材服務。助理是可編輯的規則式模板，不是連線 AI。所有處理都在訪客自己的瀏覽器中執行，不收集作品、不需登入。GitHub 託管服務仍會接收一般網站存取請求。

作品與文字草稿保存在 `localStorage`，不會跨裝置同步或公開共享。備份可攜帶文字和圖文版型；背景圖片、角色原圖、音訊與影片不會進入備份，需自行下載保存。共用裝置需留意其他使用者可存取同一瀏覽器的本機作品。偵測其他分頁更新時會阻止覆寫，請備份並重新整理。

照片每張最多 10 MB、1600 萬像素；配樂最多 20 MB。影片合成期間需保持分頁在前景，格式依瀏覽器 MediaRecorder 支援決定；無錄影支援時不影響其他功能。使用者需自行確認圖片、字型、人物與音樂授權。

## 本機開發與測試

不需建置即可啟動：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

開發測試工具使用 Node.js 24。只測純函式可直接執行 `npm test`；執行瀏覽器測試需安裝開發依賴：

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm test
npm run test:browser
```

若本機已有 Chromium，可設定 `SYSTEM_CHROMIUM=/usr/bin/chromium npm run test:browser`。測試以真正操作與檔案匯出驗證，不需任何帳號或 API key。CI 在測試通過後才部署。

## 發布

儲存庫 Settings → Pages → Source 選 **GitHub Actions**。推送 main 後執行唯一的 `Test and deploy static content to Pages` 工作流程；只發布明確列出的靜態檔案與 vendor，不發布 node_modules 或測試檔。PR 僅執行測試，不發布。GitHub Pages 免費方案一般需要公開儲存庫，限制以 GitHub 現行方案為準。

QR 碼只分享網站網址，不分享個人作品。

## LINE 官方規格來源

已於 **2026-10-26** 成功讀取並對照官方一般靜態貼圖準則：

- https://creator.line.me/zh-hant/guideline/sticker/
- https://creator.line.me/zh-hant/review_guideline/

貼圖最大 370×320、偶數尺寸；主圖 240×240；標籤 96×74；透明 PNG、RGB、72 dpi 以上；每張 ≤1 MB，ZIP 小於 60 MB；圖案四周約 10px 留白。數量 8／16／24／32／40 張。名稱／創意人／說明／版權限 40／50／160／50 字，全形算 2 字，不支援表情符號。工具檢查不等同官方審核；可讀性、內容、原創、授權與違規情況必須人工確認。生成角色僅作起點，建議加入獨特設計。

實際送審需由使用者登入 Creators Market、建立商品、上傳素材及填寫資料。本網站不代為上架，也不保證審核通過、免費販售或收益。售價、審核與分潤依 LINE 規定。

## 多樣創作工作台更新

- **整組貼圖模式**：靜態、動態 APNG、有聲創作概念可切換。六組風格文案（日常、幽默、搞笑、職場、宇宙、節慶），五種原創角色（糰子、貓、兔、機器人、星星）及多種表情。動態效果可選彈跳、搖擺、放大、扭動。
- **動態 LINE 素材**：8／16／24 張，320×270、10 格，1 秒重複 1／2／4 次；主圖為 240×240 APNG，標籤為靜態 96×74 PNG。自動檢查每張小於 1 MB、ZIP 小於 60 MB；可檢查外部 APNG 的播放格數、次數與總時間。官方來源（2026-10-26 查閱）：https://creator.line.me/zh-hant/guideline/animationsticker/
- **有聲概念**：可試聽原創電子音效，或搭配自己的音訊；輸出 APNG、獨立音效與本機預覽頁。APNG 格式本身不能嵌入聲音，官方一般公開準則未提供有聲商品申請規格，因此此 ZIP 明確標為「不可直接送審」，需向 LINE 確認資格與規格。不保證可申請有聲 LINE 商品。
- **免費本機去背**：自動處理邊緣連通、與主要背景色相近的像素，支援容差／柔化、擦除／恢復筆刷與透明 PNG 下載。處理畫布最長邊縮至 1024px，原檔不會改動或上傳。這是色彩與連通區域演算法，**不是 AI 主體分割，不保證完美去背**；複雜背景、同色主體、透明物件與髮絲需手動修邊。
- **圖文設計**：六種版型（極簡、雜誌、漸層、拼貼、海報、復古），六種配色、三種字體、點綴色與頁眉短句；版型設定隨作品備份／重開。
- **提示詞任務工作台**：關鍵字辨識後，實際切換至本站對應工具並建立可編輯草稿。可收藏任務、匯出 JSON，以及建立指定網站的 Playwright 範本（導覽、選填指定欄位、截圖）。**無法在靜態網站中直接控制任意外站、登入帳號或桌面軟體**。外站範本需使用者在本機安裝 Node.js／Playwright 自行執行，僅允許指定主機的主頁導覽，不自動按送出或登入；有自動儲存的網站，填入欄位仍可能改變資料，執行前須自行確認權限與網站行為。桌面軟體需另行接入其官方 API。
- **作品控制台**：清單／卡片／精簡／狀態看板、靈感／製作中／完成／封存、標籤與搜尋、另存副本、批次收藏／完成／封存／ZIP 下載／刪除。支援復原上次刪除（本次分頁工作階段，重新整理後清除），原有 JSON 備份相容。

所有功能仍採免費本機處理；未接入付費 AI、去背 API、音效庫或外部自動化服務。操作外部網站前需確認該網站的服務條款與可能費用。

## 文字與上傳角色的情緒動作對應

貼圖工坊現在依每句文字判讀情緒，支援感謝／道歉鞠躬、加油跳躍、晚安休息、開心大笑、喜歡比心、難過落淚、生氣跺腳、驚訝、招呼、疲倦與疑惑。無法判讀時使用自然姿勢，不再以文字雜湊隨機指定表情；也處理「不要哭」「不生氣」等常見否定語句。規則判讀可能不理解反諷、雙關或複雜語境，每張預覽下方可單獨改選情緒動作，同一句文字的不同張也能分別設定。

上傳圖片預設保留原有五官，套用整體縮放、傾斜、位移與情緒符號；這是 2D 角色合成，不是 AI 生成，也不會自動生成新肢體。需要改變五官時，展開「上傳角色：文字動作與五官設定」，勾選「重繪臉部」，手動設定臉部中心、寬高與覆蓋膚色／毛色。指定區域會被覆蓋並繪製對應的眼睛和嘴型；任意照片、側臉或複雜角色不保證自然，請先預覽並自行調整。未勾選不會改繪原臉。

靜態素材顯示各情緒的代表姿勢，動態素材逐格重繪角色；文字保持固定，主圖同樣使用第一句的情緒。動態預覽與 APNG 匯出共用同一套角色渲染，不再把整張文字圖片一起旋轉。表情區域參數與逐張選擇可隨文字草稿保存；原圖不會上傳或進入 JSON 備份，重新開啟時仍需選取原圖、重新去背／修邊，並自行勾選是否覆蓋五官。
